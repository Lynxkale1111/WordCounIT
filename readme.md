# Word Frequency Counter - TDA548 Lab 1

This repository is dedicated to the first lab in the course TDA548 at Chalmers University. 

## Project overview

This lab aims to create a python program that analyzes text document by counting the frequency at which words occur. The program tokenizes text, counts word occurrences, and displays the most common words. 

## Files
- **wordfreq.py** - Core program containing three functions
  - tokenize(lines) - Splits text into words (includes handling of punctuation, symbols and digits)
  - countWords(words,stopWords) - Counts word frequencies, ignoring stop words
  - printTopMost(frequencies,n) - Prints the *n* most frequent words.  
- **topmost.py** - Program that takes a text file, url or stop word list, and an integer *n*. It uses *wordfreq.py* to print the top *n* most frequent words.
